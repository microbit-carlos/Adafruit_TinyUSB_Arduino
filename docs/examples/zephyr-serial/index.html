Instructions:

- Build the Zephyr WebUSB serial example on a compatible board (e.g. Raspberry Pi Pico) as shown at the end of this page.
- Open the dev console to see the WebUSB transfer times.
- Click "Connect To WebUSB Device" and select the device from the popup.
- Click on "Send Alphabet" to send the alphabet one character at a time.
- Look at the console to see the transfer times for each character, and the total time to send the whole alphabet.








Tested with a Raspberry Pi Pico and the default WebUSB serial example:


    $ docker run --rm -it \
    -v $(pwd):/workdir \
    -w /workdir \
    ghcr.io/zephyrproject-rtos/zephyr-build:main \
    bash

And inside the container:


    west init .
    west update hal_rpi_pico cmsis mbedtls
    west build -b rpi_pico zephyr/samples/subsys/usb/webusb
